# By.danijoyeria — Sitio Web Oficial

Catálogo web de joyería en **Oro Laminado 18k** (`@_by.danijoyeria`), ubicado en Magangué, Bolívar, con envíos a toda Colombia.

## Estructura de Carpetas

- `index.html` — Estructura principal de la página (inspirada en Élite Joyería).
- `styles.css` — Diseño elegante en tonos dorado, crema y negro.
- `app.js` — Carga dinámica del catálogo, filtro por categorías y botón directo a WhatsApp.
- `data/productos.json` — **Base de datos de tus joyas y número de WhatsApp.**
- `img/logo/` — Coloca aquí el logo como `logo.png`.
- `img/banners/` — Imágenes de portada (opcional).
- `img/productos/` — Coloca aquí las fotos de cada joya (ej: `pulsera-medalla.jpg`, `anillo-esmeralda.jpg`, etc.).
